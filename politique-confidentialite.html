Politique de confidentialité

Comment les informations envoyées via le site et le formulaire de devis sont utilisées.

Courriel : mgalant.formations33@gmail.com.

2. Données recueillies

Lorsque vous envoyez une demande de devis depuis le site, les champs du formulaire peuvent contenir :

  • le nom ou le nom de l'entreprise ;
  • l'adresse e-mail ;
  • le numéro de téléphone, si vous le renseignez ;
  • la prestation souhaitée ;
  • le contenu de votre demande (lieu, dates et précisions que vous choisissez de fournir).

Les champs obligatoires sont indiqués comme tels dans le formulaire.

3. Finalités et base juridique

Ces données sont utilisées pour recevoir la demande, répondre aux questions, préparer un devis et, le cas échéant, organiser la prestation demandée. La base juridique est l'exécution de mesures précontractuelles prises à votre demande (article 6, paragraphe 1, point b, du RGPD). Les données nécessaires à l'exécution ou au suivi d'une prestation peuvent ensuite être traitées conformément aux obligations contractuelles et légales applicables.

4. Destinataires et services utilisés

Les informations sont destinées à MGFORMATIONS33 et sont transmises par le service technique de formulaire Formspree (formspree.io). Leur transmission peut donner lieu à des enregistrements dans les systèmes de ce prestataire. Le site est hébergé par GitHub Pages, qui traite des données techniques de connexion, notamment l'adresse IP, pour des besoins de sécurité.

Une carte OpenStreetMap est intégrée au site : son affichage peut entraîner une communication de données techniques au service cartographique. Les liens vers Facebook ouvrent un service externe régi par ses propres règles.

5. Durée de conservation

Les données liées à une demande sont conservées pendant le temps utile à son traitement et à son suivi. Pour une personne qui n'est pas devenue cliente, elles ne devraient pas être conservées au-delà de trois ans après le dernier contact émanant de cette personne, sauf justification particulière. Lorsqu'une prestation est conclue, certains documents peuvent être conservés plus longtemps afin de respecter les obligations légales, comptables ou de preuve.

6. Vos droits

Selon les conditions prévues par le RGPD, vous pouvez demander l'accès, la rectification, l'effacement, la limitation ou la portabilité de vos données, ainsi que vous opposer à certains traitements.

Pour exercer vos droits : mgalant.formations33@gmail.com. Vous pouvez également déposer une réclamation auprès de la CNIL.

7. Cookies et fonctionnalités techniques

Le code actuel du site ne comprend pas d'outil de publicité ciblée ou de mesure d'audience. Un stockage local dans le navigateur peut être utilisé pour conserver temporairement les modifications effectuées par le propriétaire via l'éditeur du site. Les services externes intégrés ou ouverts depuis le site peuvent appliquer leurs propres règles en matière de données et de traceurs.
